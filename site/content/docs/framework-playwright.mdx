## Discovery and prerequisites

Detection recognizes `playwright.config.*`, `playwright-ct.config.*`, or an `@playwright/test` dependency alongside test files. Provision the browsers and any application services that the native project requires.

## Execute and focus

```bash
gavel test playwright --dry-run .
gavel test playwright .
gavel test playwright ./web -- --project chromium --grep login
```

Replace example paths and test names with your project. Arguments after `--` go to the selected framework. Browser projects, authentication state, retries, and web-server configuration stay in Playwright config. Gavel writes a native JSON report under `.playwright/`.

## Configure the adapter

```yaml
test:
  frameworks:
    playwright:
      runtime:
        timeout: 5m
        mem: 2GiB
```

`test.frameworks.playwright.args` supplies native runner arguments; nonempty lists replace inherited lists. Global execution and reporting options are covered by [Test execution](/docs/test-execution) and [Reporting](/docs/reporting).

## Results

The adapter executes `playwright test --reporter=json` with Gavel's report settings, then converts native results into the shared test tree. Use `--failed <snapshot>` to verify a repair, and `--show-passed` to expose successful tests. A package deadline is separate from the whole-run deadline.

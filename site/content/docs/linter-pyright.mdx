## Detection and native configuration

Detection input: `pyrightconfig.json` or `pyproject.toml`. Explicit selection pins this tool; matching source files and an available executable are still required. Inspect planned commands before execution:

```bash
gavel lint pyright --dry-run
gavel lint pyright
gavel lint pyright --changed
```

Interpreter, import paths, and type-checking policy belong in Pyright configuration. Pyright reports type errors and does not provide native source fixes.

## Configure execution

```yaml
lint:
  linters:
    pyright:
      enabled: true
      runtime:
        timeout: 2m
        mem: 1GiB
```

`lint.linters.pyright.args` supplies native tool arguments. Process settings inherit from `runtime` and `lint.runtime`; explicit invocation settings take precedence. Native rule configuration is separate from these Gavel orchestration fields.

## Findings and reruns

```bash
mkdir -p .tmp
gavel lint pyright --format "json=.tmp/pyright.json,markdown=.tmp/pyright.md"
gavel lint pyright --failed
```

Standalone lint JSON is an array of tool results. For an explicit rerun or baseline, save the snapshot named by `.gavel/last.json`, as shown in [Reporting](/docs/reporting). Changed and baseline filters affect which findings are reported, and do not necessarily narrow native analysis to the same files. See [Lint execution](/docs/lint-execution) for common filters and repair behavior.

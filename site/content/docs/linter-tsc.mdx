## Detection and native configuration

Detection input: `tsconfig.json`. Explicit selection pins this tool; matching source files and an available executable are still required. Inspect planned commands before execution:

```bash
gavel lint tsc --dry-run
gavel lint tsc
gavel lint tsc --changed
```

Alias: `gavel lint typescript`. Compiler options and project references remain in TypeScript config. Gavel's adapter normalizes compiler diagnostics; it does not provide native fixes.

## Configure execution

```yaml
lint:
  linters:
    tsc:
      enabled: true
      runtime:
        timeout: 2m
        mem: 1GiB
```

`lint.linters.tsc.args` supplies native tool arguments. Process settings inherit from `runtime` and `lint.runtime`; explicit invocation settings take precedence. Native rule configuration is separate from these Gavel orchestration fields.

## Findings and reruns

```bash
mkdir -p .tmp
gavel lint tsc --format "json=.tmp/tsc.json,markdown=.tmp/tsc.md"
gavel lint tsc --failed
```

Standalone lint JSON is an array of tool results. For an explicit rerun or baseline, save the snapshot named by `.gavel/last.json`, as shown in [Reporting](/docs/reporting). Changed and baseline filters affect which findings are reported, and do not necessarily narrow native analysis to the same files. See [Lint execution](/docs/lint-execution) for common filters and repair behavior.

## Discovery and prerequisites

Detection recognizes `jest.config.*`, `.jestrc.*`, `package.json`'s `jest` field, or a Jest dependency alongside test files.

## Execute and focus

```bash
gavel test jest --dry-run .
gavel test jest .
gavel test jest ./web -- --runInBand --testNamePattern parser
```

Replace example paths and test names with your project. Arguments after `--` go to the selected framework. Gavel chooses the package manager from the project and writes a native report under `.jest/` before parsing it into the common test report.

## Configure the adapter

```yaml
test:
  frameworks:
    jest:
      runtime:
        timeout: 5m
        mem: 2GiB
```

`test.frameworks.jest.args` supplies native runner arguments; nonempty lists replace inherited lists. Global execution and reporting options are covered by [Test execution](/docs/test-execution) and [Reporting](/docs/reporting).

## Results

The adapter executes `jest --json` with Gavel's report settings, then converts native results into the shared test tree. Use `--failed <snapshot>` to verify a repair, and `--show-passed` to expose successful tests. A package deadline is separate from the whole-run deadline.

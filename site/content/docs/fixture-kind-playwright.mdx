Use the `playwright` step to run a Playwright fixture spec or a supported background watcher.

## Example

```yaml
kind: Fixture
name: Playwright example
steps:
  - id: browser_checks
    kind: playwright
    file: e2e/login.spec.ts
    cwd: .
    url: http://localhost:8080
```

Save the document as a `.fixture.yaml` file. Inspect it with `gavel fixtures outline <file>`, then execute it with `gavel fixtures <file>` once its prerequisites are available.

## Configuration and prerequisites

Foreground execution invokes `pnpm exec playwright test`, so pnpm must be installed even when the package normally uses another package manager. The package also needs `@playwright/test`, its browser dependencies, and the selected spec. `file` resolves relative to the fixture file. `script` accepts inline TypeScript written to a generated spec without templating. `url` is exported to the script as `TARGET_URL`.

## Results and lifetime

Foreground runs expose `exitCode`, `total`, `passed`, `failed`, `skipped`, `tests`, and streams. A malformed report or empty test run fails.

With `background: true`, the integration runs the watcher directly through Node. Use a script that Node can execute, emit a newline-delimited JSON `{"type":"ready"}` event when ready, and handle SIGTERM by cleaning up and exiting with code zero. `readyTimeout` bounds the wait for readiness and `stopTimeout` bounds shutdown. A normal Playwright test spec does not automatically implement this watcher protocol.

Use [Playwright test framework](/docs/framework-playwright) for ordinary project test discovery; this page describes the fixture kind.

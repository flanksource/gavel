Gavel is a single CLI that runs your tests, linters, and declarative Markdown fixtures — locally and in CI.

## Install

The CLI is a single Go binary. The easiest install is through the Go toolchain:

```bash
go install github.com/flanksource/gavel/cmd/gavel@latest
```

Prefer a prebuilt binary? Download a release from [the releases page](https://github.com/flanksource/gavel/releases) and drop it in your `$PATH`.

<Callout variant="tip" title="Shell completion">
  Run `gavel completion --help` to generate completion scripts for bash, zsh, fish, or PowerShell.
</Callout>

## Run tests

From the root of any Go project:

```bash
gavel test
```

Gavel discovers your `go test` packages, runs them, and writes a structured `dist/tests.json` plus a browsable `dist/tests.html`. Pass `--lint` to also run every linter whose config file is present in the repo.

## Lint in parallel

```bash
gavel lint
```

Supported linters (activated when their native config or project signal is discovered):

- **Go**: golangci-lint
- **Python**: ruff, pyright
- **TypeScript/JavaScript**: eslint, oxlint, react-doctor (React dependency), tsc
- **Markdown & prose**: markdownlint, vale
- **Cross-cutting**: jscpd (duplicate code), betterleaks (secrets)

All run concurrently and merge into a single report.

## Run declarative fixtures

```bash
gavel fixtures checks.fixture.md
```

Fixtures combine Markdown tables, executable command blocks, test/lint runner
steps, CEL assertions, and optional AI review steps. TODO `## Verification`
sections use the same fixture engine.

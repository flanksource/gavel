## Detection and native configuration

Detection input: `ruff.toml` or `pyproject.toml`. Explicit selection pins this tool; matching source files and an available executable are still required. Inspect planned commands before execution:

```bash
gavel lint ruff --dry-run
gavel lint ruff
gavel lint ruff --changed
```

`--fix` enables Ruff's native fixes and edits source. Python lint rules and target-version choices belong in Ruff configuration.

## Configure execution

```yaml
lint:
  linters:
    ruff:
      enabled: true
      runtime:
        timeout: 2m
        mem: 1GiB
```

`lint.linters.ruff.args` supplies native tool arguments. Process settings inherit from `runtime` and `lint.runtime`; explicit invocation settings take precedence. Native rule configuration is separate from these Gavel orchestration fields.

## Findings and reruns

```bash
mkdir -p .tmp
gavel lint ruff --format "json=.tmp/ruff.json,markdown=.tmp/ruff.md"
gavel lint ruff --failed
```

Standalone lint JSON is an array of tool results. For an explicit rerun or baseline, save the snapshot named by `.gavel/last.json`, as shown in [Reporting](/docs/reporting). Changed and baseline filters affect which findings are reported, and do not necessarily narrow native analysis to the same files. See [Lint execution](/docs/lint-execution) for common filters and repair behavior.
